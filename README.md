Sitio web moderno y responsivo desarrollado para una tienda de mates y accesorios.
El proyecto cuenta con un diseño atractivo, navegación fluida y una estética inspirada en la cultura matera argentina, utilizando una paleta de colores cálida y natural.

🚀 Características
Diseño responsive adaptable a celulares, tablets y PC.
Interfaz moderna con HTML, CSS y JavaScript.
Secciones de productos destacadas.
Animaciones y efectos visuales suaves.
Optimización visual enfocada en experiencia de usuario.
🛠️ Tecnologías utilizadas
HTML5
CSS3
JavaScript
